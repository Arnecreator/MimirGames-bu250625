Instruction for Replit – Replace Popup Edit with Inline Table Editing
Goal:
Replace the current "Edit User" popup with inline editing inside the table itself. Admins should be able to double-click a cell (e.g. username or email), edit it directly, and when they leave the field or press Enter, the change should be saved to the database via a PATCH request.

🔧 Step-by-step instructions:
Remove the existing JSON popup edit modal entirely.
This includes the button trigger and modal HTML/CSS.

In the table rendering function (likely renderUserRow), make the username and email cells editable on double-click.

Add the following helper function to handle inline editing:

function makeCellEditable(td, field, userId) {
  const originalText = td.textContent;
  const input = document.createElement("input");
  input.type = "text";
  input.value = originalText;
  input.style.width = "100%";
  input.style.fontSize = "inherit";
  input.style.border = "1px solid #ccc";
  input.style.padding = "2px";

  input.addEventListener("keydown", (event) => {
    if (event.key === "Enter") {
      input.blur();
    }
    if (event.key === "Escape") {
      td.textContent = originalText;
    }
  });

  input.addEventListener("blur", () => {
    const newValue = input.value.trim();
    td.textContent = newValue;

    if (newValue !== originalText && newValue !== "") {
      fetch(`/api/users/${userId}`, {
        method: "PATCH",
        headers: {
          "Content-Type": "application/json",
        },
        body: JSON.stringify({ [field]: newValue }),
      })
      .then((res) => {
        if (!res.ok) {
          alert("Failed to update user.");
          td.textContent = originalText;
        }
      })
      .catch(() => {
        alert("Network error.");
        td.textContent = originalText;
      });
    }
  });

  td.textContent = "";
  td.appendChild(input);
  input.focus();
}
