Instructions for Improving UI Consistency, Mobile Responsiveness, and Readability Across All Pages (Admin & Main)
1. Fix Topbar Overflow on Mobile
File: public/components/topbar.html
Problem: The navigation bar overflows horizontally on mobile devices and requires horizontal scrolling.

Action:

html
Copy
Edit
<style>
  nav {
    flex-wrap: wrap;
    overflow-x: hidden;
  }
  nav a, nav span, nav button {
    font-size: 12px; /* smaller for mobile */
    margin: 2px 4px;
  }

  @media screen and (max-width: 600px) {
    nav {
      justify-content: center;
    }
    nav a, nav span, nav button {
      font-size: 10px;
    }
  }
</style>
Result: Menu items wrap to new lines if needed and don’t overflow the screen. Font size is reduced for mobile.

2. Make Topbar Uniform Across All Pages
Ensure topbar.html is included via <include> or similar reuse method in:

index.html

users.html

friends.html

leaderboard.html

Goal: All pages should share identical topbar layout and style.

3. Reduce Header Font Sizes
Issue: Elements like “Welcome, Marcus33*” and section headers (e.g. Your Stats) are too large and overwhelming, especially on mobile.

Action (example):

css
Copy
Edit
h1, h2, h3 {
  font-size: 16px;
  font-weight: 600;
  margin: 6px 0;
}

@media screen and (max-width: 600px) {
  h1, h2, h3 {
    font-size: 14px;
  }
}
4. Soften Green Text
Problem: Neon green (#00FFCC or similar) is too bright against dark background.

Suggested Color Change:

css
Copy
Edit
/* Old bright green */
color: #00FFCC;

/* Replace with softer tone */
color: #7fffd4; /* aquamarine */
Apply to:

Section titles like “Friends & Stats”

Login greetings

Stat labels like Qpd, #answ, etc.

5. Make Stats Sections More Compact
In friends.html and stats-related views:

Reduce padding/margin of stat cells.

Use smaller font-size (11–12px).

Decrease line height to 1.2.

Example:

css
Copy
Edit
.table th, .table td {
  padding: 4px 6px;
  font-size: 12px;
  line-height: 1.2;
}
